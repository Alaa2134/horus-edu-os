Build System

How HORUS OS Is Built

  • Step 1: debootstrap → clean Ubuntu 22.04 rootfs in chroot
  • Step 2: Mount pseudo-filesystems, copy DNS, set APT sources
  • Step 3: Install 80+ packages inside chroot environment
  • Step 4: Apply HORUS branding — themes, GTK, Plymouth, GRUB
  • Step 5: Install 5 custom apps to /opt/horus/
  • Step 6: mksquashfs → xorriso → bootable hybrid ISO
# One command, full ISO
