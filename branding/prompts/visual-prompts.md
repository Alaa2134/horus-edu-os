## Tips for Best Results

### Midjourney Parameters to Add:
```
--ar 16:9       (for wallpapers)
--ar 1:1        (for icons)
--ar 2:3        (for posters)
--v 6           (latest model)
--style raw     (more photorealistic)
--q 2           (higher quality)
```

### Negative Prompts (Midjourney `--no`):
```
--no text, watermarks, logos, people, faces, cartoon style, 
oversaturated colors, light backgrounds, white backgrounds
```

### DALL·E 3 Tips:
- Add "in the style of a professional tech startup brand" for cleaner results
- Specify "no text or words in the image"
- Request "dark background, dark mode aesthetic"

### Color Codes to Mention:
- Background: `deep black #0a0a0f`
- Primary: `neon gold #c9a227`  
- Accent: `electric cyan #00d4ff`
- Secondary: `electric blue #1a73e8`
