══════════════════════════════════════════════════════════
الطريقة ١: USB Flash Drive (الأفضل)
══════════════════════════════════════════════════════════
1. حمّل الـ ISO من صفحة التحميل
2. تحقق من الـ SHA256:
   sha256sum -c horus-edu-os-1.0.0-amd64.iso.sha256
3. فلّش على USB:
   - Windows: استخدم Rufus (GPT + UEFI)
   - Linux/Mac: dd if=*.iso of=/dev/sdX bs=4M status=progress
4. أعد الإقلاع من USB
5. اختر "جرّب" أو "ثبّت" من GRUB

══════════════════════════════════════════════════════════
الطريقة ٢: VMware Workstation/Player
══════════════════════════════════════════════════════════
1. حمّل ملف horus-edu-os.vmx (مضمّن معك)
2. File → Open → اختر horus-edu-os.vmx
3. ضع الـ ISO في نفس المجلد
4. Power On — يقلع تلقائياً من الـ ISO
إعدادات مقترحة: RAM 4GB · CPU 2 cores · Secure Boot OFF

══════════════════════════════════════════════════════════
الطريقة ٣: VirtualBox
══════════════════════════════════════════════════════════
1. New → Linux · Ubuntu 64-bit
2. RAM: 4096 MB · VDI: 30 GB
3. Settings → Storage → أضف الـ ISO
4. Settings → System → Enable EFI
5. Start
