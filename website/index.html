جامعة حورس للعلوم والتكنولوجيا

Horus Edu OS هو نظام التشغيل الرسمي لطلاب جامعة حورس، مصمم خصيصاً لتوفير بيئة تعليمية متكاملة تجمع بين قوة Linux ومرونة التعليم الحديث.


𓂋 HORUS UNIVERSITY · LEARNING WITHOUT LIMITS 𓂀

المميزات

لماذا Horus Edu OS؟

نظام تشغيل مبني للتعليم من الأساس، ليس مجرد Linux عادي

🏛
واجهة عربية كاملة
واجهة مستخدم بالكامل باللغة العربية مع دعم RTL، مصممة لراحة الطالب العربي بشكل كامل.
🤖
مساعد AI محلي
مساعد ذكاء اصطناعي يعمل بدون إنترنت باستخدام Ollama + Llama 3، يشرح المواد ويساعد في حل المسائل.
🔒
آمن ومحمي
مبني على Ubuntu 22.04 LTS مع AppArmor وsystemd sandboxing وتشفير كامل لبيانات الطالب.
⚡
خفيف وسريع
XFCE4 مع picom compositor يعمل بكفاءة على أجهزة بـ 4GB RAM، مثالي لمعامل الجامعة.
📡
يعمل بدون إنترنت
جميع التطبيقات والمحتوى متاحة offline، الطالب لا يحتاج اتصال دائم للاستفادة الكاملة.
🎓
مخصص للجامعة
تكامل مباشر مع منهج جامعة حورس، مكتبة رقمية للكتب الدراسية والمراجع العلمية المعتمدة.

اختبر على Windows الآن بدون ISO
شغّل PowerShell كـ Administrator ونفّذ الأمر التالي — سيثبّت WSL2 ويشغّل كل التطبيقات تلقائياً:
.\scripts\wsl-quickstart.ps1
  1. حمّل ملف ISO من الرابط أعلاه بمجرد توفره
  2. تحقق من سلامة الملف: sha256sum -c sha256sum.txt
  3. Windows: افتح Rufus → اختر ISO → GPT + UEFI → Start
  4. Linux/Mac: sudo dd if=horus-edu-os.iso of=/dev/sdX bs=4M status=progress
  5. أعد تشغيل الحاسوب وادخل BIOS → Boot from USB
  6. اختر "جرّب Horus" أو "ثبّت Horus" من قائمة GRUB
  1. حمّل ملف horus-edu-os.vmx من الأعلى
  2. افتح VMware Workstation أو VMware Player
  3. File → Open → اختر ملف horus-edu-os.vmx
  4. ضع ملف ISO في نفس مجلد ملف الـ VMX
  5. اضغط Power On → سيقلع تلقائياً من الـ ISO
  6. الإعدادات المقترحة: RAM 4GB · CPU 2 · Secure Boot OFF
  1. افتح VirtualBox → New
  2. الاسم: Horus Edu OS · النوع: Linux · Ubuntu 64-bit
  3. RAM: 4096 MB · VDI: 30 GB
  4. Settings → Storage → أضف ملف ISO
  5. Settings → System → Enable EFI
  6. Start → سيقلع من الـ ISO تلقائياً
  1. قم بعمل نسخة احتياطية لبياناتك أولاً !
  2. حمّل Horus Edu OS ISO وفلّشه على USB
  3. من Windows: Disk Management → حرر مساحة 40GB+
  4. أقلع من USB → اختر "Install Horus Edu OS"
  5. في المثبّت: "Install alongside existing OS"
  6. GRUB سيظهر عند كل إقلاع لاختيار النظام
