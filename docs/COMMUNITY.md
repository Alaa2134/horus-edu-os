# HORUS OS — Community, Growth & Landing Copy

---

## 1. Community & growth strategy

**Launch (month 0–1)**
- **YouTube launch video** (3–5 min): the setup-pain problem → plug in an
  Arduino → it's detected → scaffold a project → run it. End on "Download Alpha".
- **GitHub**: public repo, clear README, good first issues, MIT-licensed core.
- **Show, don't tell**: a 60-sec "boards just work" clip for socials.

**Build the base (month 1–3)**
- **Discord + Telegram** community; channels for Arduino, ESP32, AI, ROS, help.
- **Arabic tutorials** (written + video) — the differentiator.
- **Project templates**: invite the community to submit starters (PRs).

**Grow through institutions (month 3–9)**
- **University ambassador program**: one student rep per faculty; free swag,
  early builds, a "HORUS Lab" badge.
- **Robotics-competition demos**: HORUS kiosk + Competition Mode at events.
- **Lab pilots**: help a faculty image one lab; gather testimonials.

**Sustain (ongoing)**
- Monthly release notes, a public roadmap, contributor shout-outs.
- "HORUS Certified Maker/AI/Robotics" learning track (later).

## 2. Open-source strategy
- Core distro, apps, scripts, branding, docs: **MIT** (system components keep
  their original licenses).
- Semantic versioning; `main` protected; PRs + CI ISO build on tag.
- `CONTRIBUTING.md` + `CODE_OF_CONDUCT.md` (to add): how to add a template, an
  app, a translation, or a tutorial. Label `good first issue` generously.
- Templates and Store content via PR with a simple `horus.json` manifest.

## 3. Contribution guidelines (summary)
- **Templates:** add a folder under `templates/` with runnable code + `horus.json`.
- **Apps:** FastAPI backend + self-contained HTML (or React → built at ISO time).
- **Translations:** Arabic/English strings; keep RTL correct.
- **Tutorials:** markdown in `docs/`; bilingual where possible.
- Keep the brand: gold `#c9a227`, dark surfaces, beginner-first tone.
